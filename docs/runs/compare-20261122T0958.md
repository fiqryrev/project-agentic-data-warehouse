Accuracy counts `exact_match` and `within_tolerance`. Cost is the gateway's list price of the
`auto-ontology` calls linked to each answer (caller key and time window); NVIDIA prices are an
estimate at the OpenRouter list price of the same model (M9). p95 latency is over the candidate's
chat calls in the run's window, from the gateway's spend log.

**Cost corrected after review (#33).** The first version of this report summed each answer's
linked calls, and the padded windows of back-to-back questions overlap, so a call could count for
two answers. The cost columns above count every `auto-ontology` call in the candidate's run window
once (gateway spend log); the per-answer linking is fixed in `llm/ask.py` (`owner_of`). The two
rows of this run in `rpt__ops__provider_comparison__snapshot` keep the old, higher linked cost.
